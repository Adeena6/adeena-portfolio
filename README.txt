# Adeena Shaikh — Developer Portfolio

## Run locally
1. Extract this folder if it came as a ZIP.
2. Open `adeena-portfolio` in Visual Studio Code.
3. Open `index.html` and use **Open with Live Server** if you have the VS Code Live Server extension.
4. If you do not have Live Server, double-click `index.html` in File Explorer to preview the static site.

## Before publishing
- In `index.html`, the contact email is set to adeenashaikh06@gmail.com; update it in `index.html` if it changes.
- Add your real resume file and a download link if you want a CV download button.
- Add repository/demo links to each project when available.
- Check that every listed skill and project description accurately reflects your experience.
- The page uses Google Fonts; an internet connection is needed to load those fonts. The site itself does not require a build step.

## Publish with Vercel
1. Create a GitHub repository and upload these three files.
2. Sign in to Vercel with GitHub.
3. Choose **Add New → Project**, import the repository, and deploy with the default settings.
4. Vercel will provide a live `*.vercel.app` URL.

The CV PDF is included at `assets/Adeena_Shaikh_CV.pdf`. Replace that file if you update your CV, keeping the same filename so the website links continue to work.
